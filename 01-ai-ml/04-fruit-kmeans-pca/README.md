# 과일 이미지 K-Means·PCA 응용

## 실습 내용

- 과일 이미지 배열을 `.npy`로 변환
- K-Means로 레이블 없이 이미지 군집화
- 군집별 이미지 수와 클러스터 중심 시각화
- 엘보우 방법으로 군집 수 탐색
- PCA로 10,000개 픽셀 특성 축소
- 복원 이미지와 누적 설명 분산 확인
- PCA 특성을 로지스틱 회귀에 연결해 분류 성능 비교

## 응용 데이터

기존 실습의 사과·파인애플·바나나 외에 키위·망고·오렌지·딸기 4종을 사용했습니다. 대용량 원본 데이터는 저장소에 포함하지 않으며 노트북 실행 시 내려받습니다.
