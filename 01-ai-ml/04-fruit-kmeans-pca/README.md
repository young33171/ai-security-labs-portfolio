# 과일 이미지 K-Means·PCA 응용

과일 사진을 픽셀 배열로 변환한 뒤 평균 이미지, K-Means 군집화, PCA 차원 축소, 로지스틱 회귀 분류까지 연결한 실습입니다. 기존 수업 예제를 재현한 후, 실습하지 않은 과일 4종을 선정하여 같은 분석 절차를 새 데이터에 적용했습니다.

## 노트북 구성

| 파일 | 주요 내용 | 확인 결과 |
|---|---|---|
| `Lab_06_01_fruit_clustering.ipynb` | 이미지 배열 로드, 클래스별 평균, 평균과 가까운 이미지 탐색 | 픽셀 평균을 이용한 대표 이미지와 유사 샘플 확인 |
| `Lab_06_02.ipynb` | K-Means 학습, 레이블별 군집 개수, 중심 이미지 | 레이블 없이 형성된 군집의 특성과 오분류 원인 확인 |
| `Lab_06_03.ipynb` | PCA 학습, 설명 분산, 차원 축소와 복원 | 적은 주성분으로 보존되는 이미지 정보 확인 |
| `Lab_06_04_Fruits4_Application.ipynb` | 새로운 과일 4종 수집·변환·군집화·분류 | 수업 절차를 새로운 데이터에 적용한 종합 응용 |

## 응용 데이터

기존 사과·파인애플·바나나 예제와 겹치지 않도록 다음 4종을 선정했습니다.

| 클래스 | 선정 이유 | 예상되는 구분 특성 |
|---|---|---|
| 키위 | 작은 타원형과 갈색 계열 표면 | 외곽선, 어두운 평균 명도 |
| 망고 | 비대칭 타원형과 부드러운 표면 | 형태와 넓은 밝기 영역 |
| 오렌지 | 둥근 형태와 비교적 일정한 표면 | 원형 외곽선과 균일한 픽셀 분포 |
| 딸기 | 뾰족한 외곽선과 씨 무늬 | 삼각형 형태와 표면 질감 |

원본 이미지는 동일한 크기와 색상 표현으로 변환한 뒤 클래스별 배열을 결합하여 `.npy` 파일로 저장합니다. 대용량 원본 데이터는 저장소에 포함하지 않습니다.

## 전체 처리 과정

1. 이미지 경로와 클래스 이름을 확인합니다.
2. 모든 이미지를 동일한 크기로 조정하고 배열로 변환합니다.
3. 클래스별 배열과 레이블을 생성한 뒤 `.npy`로 저장합니다.
4. 분석을 위해 이미지 배열을 `샘플 수 × 픽셀 수`의 2차원 형태로 펼칩니다.
5. K-Means를 학습하고 각 군집의 샘플 수와 중심 이미지를 확인합니다.
6. PCA로 픽셀 특성을 축소하고 누적 설명 분산을 확인합니다.
7. 주성분으로 이미지를 복원하여 손실되는 시각 정보를 비교합니다.
8. 축소된 특성을 로지스틱 회귀에 입력하고 분류 성능을 평가합니다.

## K-Means 해석

K-Means는 실제 과일 이름을 모르는 상태에서 픽셀 거리가 가까운 이미지를 같은 군집으로 묶습니다. 따라서 군집 번호는 클래스 번호와 같은 의미가 아닙니다. 배경 밝기, 촬영 각도, 크기 차이가 과일 종류보다 크게 반영되면 서로 다른 과일이 같은 군집에 포함될 수 있습니다.

확인 항목은 다음과 같습니다.

- 군집별 샘플 개수가 지나치게 한쪽에 몰리는지
- 중심 이미지가 실제 과일의 대표 형태를 보이는지
- 군집과 실제 레이블의 대응 관계가 어느 정도인지
- 잘못 묶인 이미지에 배경·크기·회전 차이가 있는지
- 군집 수를 바꿨을 때 관성값과 결과가 어떻게 달라지는지

## PCA 해석

원본 이미지의 모든 픽셀을 특성으로 사용하면 차원이 매우 커집니다. PCA는 데이터 분산을 많이 설명하는 방향부터 새로운 축을 만들고, 일부 주성분만 사용하여 데이터 크기를 줄입니다.

- `explained_variance_ratio_`: 각 주성분이 설명하는 정보의 비율
- 누적 설명 분산: 선택한 주성분들이 전체 변동을 얼마나 보존하는지 나타내는 값
- 복원 이미지: 축소된 정보를 다시 픽셀 공간으로 되돌린 결과

주성분 수가 너무 적으면 계산량은 줄지만 과일의 윤곽과 질감이 손실될 수 있습니다. 반대로 너무 많으면 원본 정보는 잘 보존되지만 차원 축소 효과가 작아집니다.

## 분류 단계

PCA로 만든 저차원 특성을 로지스틱 회귀에 입력하여 과일 4종을 분류합니다. 이때 학습·테스트 데이터 분리, 특성 변환 순서, 클래스별 성능을 확인합니다. 단순 정확도뿐 아니라 혼동행렬을 통해 어떤 과일 쌍이 자주 혼동되는지 분석합니다.

## 결과 해석 시 한계

- 촬영 배경이 클래스마다 다르면 모델이 과일보다 배경을 학습할 수 있습니다.
- 이미지 수가 적거나 클래스별 개수가 다르면 결과가 불안정할 수 있습니다.
- K-Means는 초기 중심 선택에 따라 결과가 달라질 수 있습니다.
- PCA는 분산을 보존하지만 분류에 가장 중요한 정보만 선택하는 지도학습 방법은 아닙니다.
- 더 안정적인 비교를 위해 교차 검증, 데이터 증강, 배경 제거, CNN 기반 특성 추출을 추가할 수 있습니다.
