# 01. AI·머신러닝 실습

정보보호 데이터를 머신러닝으로 분석하고, 이미지 데이터의 차원을 축소·군집화한 실습입니다.

## 목록

| 폴더 | 내용 | 핵심 개념 |
|---|---|---|
| `00-pytorch-tensor` | 텐서 생성·추출·구조 변경·연산 | shape, dtype, indexing, reshape |
| `01-malware-knn` | K-최근접이웃 악성코드 분류 | 거리 기반 분류, 표준화, 정확도 |
| `02-phishing-logistic` | 로지스틱 회귀 피싱 분류 | 확률, 시그모이드, 혼동행렬 |
| `03-phishing-tree-comparison` | 결정트리와 세 모델 비교 | 트리 시각화, 과대적합, 모델 비교 |
| `04-fruit-kmeans-pca` | 과일 이미지 군집화·PCA·분류 | 비지도학습, 차원 축소, 설명 분산 |

## 공통 분석 흐름

1. 데이터 확인 및 결측치·레이블 점검
2. 학습/테스트 데이터 분리
3. 필요한 경우 표준화 또는 차원 축소
4. 모델 학습과 예측
5. 정확도·혼동행렬·분류 보고서 확인
6. 모델별 장단점 및 오분류 원인 정리
