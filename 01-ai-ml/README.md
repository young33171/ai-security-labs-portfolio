# 01. AI·머신러닝 실습

정보보호 데이터를 머신러닝으로 분류하고, 이미지 데이터를 군집화·차원 축소한 실습 모음입니다. 각 노트북은 데이터 로드부터 전처리, 학습, 평가, 시각화까지 하나의 분석 흐름으로 구성했습니다.

## 공통 분석 흐름

1. **데이터 구조 확인**: 행·열 개수, 자료형, 특성 이름, 레이블 의미를 확인합니다.
2. **데이터 품질 점검**: 결측치, 중복, 이상치, 클래스별 개수를 확인합니다.
3. **학습·테스트 분리**: 모델이 보지 않은 데이터로 평가할 수 있도록 데이터를 분리합니다.
4. **전처리**: 거리 기반 모델에는 표준화를 적용하고 이미지 데이터는 동일 크기로 변환합니다.
5. **모델 학습**: 모델의 핵심 하이퍼파라미터를 바꾸며 결과 차이를 확인합니다.
6. **성능 평가**: 정확도, 혼동행렬, 정밀도, 재현율, F1-score를 확인합니다.
7. **결과 해석**: 오분류 원인, 과대적합 가능성, 모델의 한계를 보안 관점에서 정리합니다.

## 세 분류 모델 비교

| 모델 | 판단 방식 | 전처리 | 장점 | 한계 |
|---|---|---|---|---|
| KNN | 가까운 학습 샘플의 다수결 | 표준화 중요 | 단순하고 결과를 직관적으로 설명 가능 | 데이터가 커질수록 예측이 느리고 이상치에 민감 |
| 로지스틱 회귀 | 특성의 선형 결합을 확률로 변환 | 표준화 권장 | 예측 확률과 특성 영향 방향을 해석 가능 | 복잡한 비선형 경계를 표현하기 어려움 |
| 결정트리 | 특성 조건을 순차적으로 분할 | 필수 아님 | 규칙 시각화가 쉽고 비선형 관계 표현 가능 | 깊이가 커지면 학습 데이터에 과대적합 |

## 보안 데이터 평가 관점

- **정탐(TP)**: 악성 대상을 악성으로 올바르게 탐지한 경우
- **정상 판정(TN)**: 정상 대상을 정상으로 올바르게 판정한 경우
- **오탐(FP)**: 정상 대상을 악성으로 잘못 차단한 경우
- **미탐(FN)**: 악성 대상을 정상으로 놓친 경우

보안 탐지에서는 정확도가 높더라도 악성 샘플을 많이 놓칠 수 있습니다. 따라서 악성 탐지 재현율과 정상 서비스 차단에 영향을 주는 오탐률을 함께 살펴봐야 합니다.

## 실습에서 추가로 고려할 사항

- 랜덤 분할 결과가 우연에 좌우되지 않도록 `random_state`를 고정합니다.
- 전처리 기준은 학습 데이터에서만 계산하여 데이터 누수를 방지합니다.
- 클래스 수가 크게 다르면 정확도 대신 클래스별 지표를 함께 확인합니다.
- 실제 보안 데이터는 시간에 따라 공격 패턴이 달라지므로 시간 순서 기반 검증도 필요합니다.
- 데이터셋에서 높은 성능이 나와도 실제 운영 환경에서 동일한 성능을 보장하지 않는다는 점을 구분합니다.
