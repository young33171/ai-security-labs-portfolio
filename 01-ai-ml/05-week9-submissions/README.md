# 9주차 과제 제출 노트북

수업에서 실제 과제로 제출한 실행 완료 `.ipynb` 파일을 별도로 모은 폴더입니다. 일반 실습 폴더에서는 주제별 학습 내용을 확인할 수 있고, 이 폴더에서는 과제 제출 당시의 구성과 출력 결과를 그대로 확인할 수 있습니다.

## 제출 파일

| 파일 | 과제 내용 | 포함된 실습 |
|---|---|---|
| `9주차_Lab_05_3_앙상블과_Iris응용_이영언.ipynb` | 트리 앙상블 및 Iris 응용 | 결정트리, 랜덤 포레스트, 그래디언트 부스팅, Iris 4개 특성 분류와 모델 비교 |
| `9주차_Lab_06_01_과일군집_확인문제_이영언.ipynb` | 군집 알고리즘과 과일 사진 분석 | 과일 배열 확인, 평균 이미지, 평균과 가까운 이미지 100장 탐색, 클래스별 개수 확인 |
| `9주차_Lab_06_04_과일4종_응용_이영언.ipynb` | 새로운 과일 4종 종합 응용 | 이미지 `.npy` 변환, K-Means, PCA, 로지스틱 회귀 |

## 과제 1: 앙상블과 Iris 응용

Iris 데이터의 `sepal_length`, `sepal_width`, `petal_length`, `petal_width` 네 가지 특성을 사용하여 품종을 예측합니다. 단일 결정트리와 여러 트리를 결합하는 랜덤 포레스트·그래디언트 부스팅을 학습하고, 각 모델의 예측 성능과 특성 중요도를 비교합니다.

주요 확인 항목:

- 데이터 크기와 클래스별 샘플 수
- 학습·테스트 데이터 분리
- 결정트리의 분할 기준과 깊이
- 랜덤 포레스트의 다수결 방식
- 그래디언트 부스팅의 순차적 오차 보완
- 모델별 정확도와 혼동행렬
- 꽃잎·꽃받침 특성의 중요도 차이

## 과제 2: 과일 군집 확인문제

바나나·파인애플·사과 이미지 배열을 불러와 클래스별 평균 이미지를 계산합니다. 각 이미지와 평균 이미지 사이의 절대 오차를 구하고, 평균과 가장 가까운 이미지 100장을 선택하여 실제 클래스가 어떻게 구성되는지 확인합니다.

주요 확인 항목:

- 이미지 배열의 차원과 픽셀 범위
- 클래스별 평균 이미지 계산
- 샘플과 평균 사이의 절대 오차
- 오차가 작은 순서대로 인덱스 정렬
- 선택된 100장의 클래스별 개수
- 평균 이미지 방식의 장점과 배경·형태 변화에 대한 한계

## 과제 3: 과일 4종 응용

기존 수업에서 사용하지 않은 키위·망고·오렌지·딸기 이미지를 동일한 크기로 변환하고 NumPy 배열로 저장합니다. 이후 K-Means로 군집을 확인하고 PCA로 픽셀 차원을 축소한 뒤 로지스틱 회귀로 분류합니다.

주요 확인 항목:

- 클래스별 이미지 파일 수와 변환 결과
- `.npy` 배열의 shape와 레이블 구성
- K-Means 군집별 데이터 개수와 중심 이미지
- PCA 주성분 수와 누적 설명 분산
- 축소 데이터의 복원 이미지
- 로지스틱 회귀의 테스트 성능과 혼동행렬

## 파일 상태

노트북에는 코드, 설명, 표, 그래프 및 실행 결과가 포함되어 있습니다. 대용량 원본 이미지와 자동 생성 `.npy` 파일은 저장소 용량과 데이터 이용 조건을 고려해 제외했으며, 데이터 준비 셀을 통해 다시 만들 수 있도록 구성했습니다.
