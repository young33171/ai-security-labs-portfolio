# SetUID 권한 실습

## 목표

실행 파일 소유자의 권한으로 프로그램이 실행되는 SetUID의 동작과 위험을 확인합니다.

## 점검 흐름

```bash
ls -l target
id
./target
find / -perm -4000 -type f 2>/dev/null
```

실행 전후의 실제 UID와 유효 UID를 비교하고, 권한 상승 가능성이 있는 파일이 불필요하게 설치되어 있지 않은지 확인했습니다.

## 배운 점

SetUID 자체가 취약점은 아니지만, 입력 검증이 부족하거나 외부 명령을 안전하지 않게 호출하는 프로그램과 결합하면 심각한 권한 상승으로 이어질 수 있습니다.
