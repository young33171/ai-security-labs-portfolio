# DLL 인젝션 교육 실습

## 목적

Windows가 프로세스에 DLL을 로딩하는 과정과 보안 제품이 비정상 모듈 로딩을 탐지하는 원리를 이해합니다.

## 검증

1. Visual Studio에서 교육용 DLL을 빌드합니다.
2. 격리된 Windows 가상머신에서 수업용 로딩 절차를 수행합니다.
3. Process Explorer의 DLL 목록에서 대상 모듈 로딩 여부를 확인합니다.
4. 테스트 종료 후 설정을 원상복구합니다.

## 방어 관점

비정상 DLL 경로, 서명되지 않은 모듈, 자동 시작 지점 변경, 프로세스별 모듈 변화를 모니터링해야 합니다.
